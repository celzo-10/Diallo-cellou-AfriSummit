** Description du projet **

AfriConnect Summit 2026 est un site web vitrine créé pour présenter un événement technologique africain organisé à Dakar, au Sénégal, du 15 au 17 octobre 2026.

Le site permet aux visiteurs de découvrir l’événement, le programme des conférences, les intervenants, les statistiques clés, les sponsors et les différentes informations pratiques.

L’objectif est de proposer une interface moderne, responsive et interactive adaptée aux ordinateurs, tablettes et smartphones.

** Technologies utilisées **

* HTML5 : structure des pages web
* CSS3 : mise en forme et design du site
* JavaScript : interactions et animations
* Bootstrap 5 : création d’une interface responsive
* Font Awesome / Bootstrap Icons : icônes
* Google Fonts : typographies
* Git & GitHub : gestion et hébergement du projet

** Fonctionnalités JavaScript implémentées **

Plusieurs fonctionnalités interactives ont été développées avec JavaScript :

* Mode sombre / mode clair
* Compte à rebours avant le début du sommet
* Animation des chiffres clés lors de l’apparition à l’écran
* Animations au scroll
* Navigation entre les différents jours du programme
* Affichage automatique de l’année dans le footer
* Bouton “Retour en haut”
* Menu de navigation responsive
* Validation des formulaires
* Interactions avec les différents éléments de la page
